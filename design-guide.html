07 — Motion

Motion Tokens

Three easing curves and four duration steps. Keep transitions short. Use ease-standard for most UI, ease-emphasized for entrances, ease-out-soft for spring-like reveals.

Durations
--dur-1
120ms — Micro interactions (hover, focus)
--dur-2
200ms — Standard transitions
--dur-3
320ms — Panel slides, layout shifts
--dur-4
480ms — Page transitions, modals
Easing Curves
--ease-standard
cubic-bezier(0.2, 0.6, 0.2, 1)
Default for all UI transitions
--ease-emphasized
cubic-bezier(0.32, 0.72, 0, 1)
Entrances, appearing elements
--ease-out-soft
cubic-bezier(0.16, 1, 0.3, 1)
Spring-like reveals, sidebars

Inline Code

Use --quantica-pink for brand foreground, and --magenta-tint as its background wash. Never hardcode #C41E54 directly.

Code Block
CSS 
.btn-primary {
  background: var(--quantica-pink);
  color: var(--fg-on-pink);
  border-radius: var(--radius-pill);
  padding: 8px 20px;
  box-shadow: var(--shadow-pink-soft);
  transition: background var(--dur-2) var(--ease-standard);
}

.btn-primary:hover {
  background: var(--deep-berry);
}
Blockquote

Design tokens are the single source of truth. Every color, size, and motion value in the system traces back to a named token — never a hardcoded value.
